# The Frame Studio

A responsive static website for The Frame Studio, built using HTML, CSS, and JavaScript.

## About the Project

The Frame Studio website is a static frontend project designed to present the studio's online presence through a clean and accessible web experience.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```text
the-frame-studio/
│
├── index.html
└── README.md
```

## Getting Started

### Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/yashodharamogaveer-ops/the-frame-studio.git
   ```

2. Open the project folder.
3. Open `index.html` in your web browser.

No additional dependencies or build tools are required.
